# Report Template

Use this structure unless the user requests a different format.

## Financial Audit for [Period]

### TL;DR

State the period, opening net worth, closing net worth, net worth change, net savings rate, full burn rate, required runway, and the most important red flag in one short paragraph.

### Data Quality and Assumptions

List missing data, classification assumptions, currency assumptions, and any double-counting risks.

### 1. Net Worth

- Opening assets
- Opening liabilities
- Opening net worth
- Closing assets
- Closing liabilities
- Closing net worth
- Change in net worth
- Main drivers

### 2. Income by Source

Group by source and state concentration risk. Separate true income from refunds, reimbursements, gifts, and transfers.

### 3. Expenses by Type

Report fixed, variable, discretionary, one-off, fees, and interest. Explain what dominates spending.

### 4. Savings Rate

Report gross savings rate if gross income is available. Report net savings rate if net income is available. Explain whether visible savings excludes payroll deductions or retirement contributions.

### 5. Burn Rate and Runway

Report required burn, full burn, liquid emergency assets, required runway, and full runway. Compare runway with the user's target if provided.

### 6. Top 10 Expense Categories

Rank by amount. Include percentage of total expenses when possible.

### 7. Top 10 Money Leaks

Rank by likely actionability, not only size. Include the evidence and the likely monthly impact.

### 8. Previous Period Comparison

Compare against the prior period if available. Otherwise state that this period becomes the baseline.

### 9. Red Flags

Cover income concentration, emergency fund, debt load, currency risk, recurring waste, lifestyle inflation, and missing data.

### 10. Decision Notes

Prioritize decisions in this order:

1. Data cleanup required before trusting the numbers.
2. Emergency fund adequacy.
3. High-interest debt and minimum-payment risk.
4. Burn rate reduction opportunities.
5. Savings automation.
6. Investment discussion only after emergency fund and debt checks.

Do not recommend specific investments. If the user asks for investing ideas before emergency fund and debt are evaluated, redirect to those prerequisites first.
