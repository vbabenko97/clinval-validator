# Kimi K2.6 Prompting Guide Skill

This folder contains a reusable `SKILL.md` for creating, reviewing, and improving prompts for Moonshot AI Kimi K2.6.

## Files

- `SKILL.md` — the actual skill.

## Intended use

Use the skill when writing prompts for Kimi K2.6 coding, agentic workflows, tool use, long-context analysis, multimodal analysis, research synthesis, and prompt rewriting.

## Source basis

Built from Kimi/Moonshot documentation available on 2026-05-16, especially the Kimi K2.6 quickstart, Kimi prompt best-practices page, and Kimi thinking-model usage documentation.
